Documentación Técnica

SISTEMA INTEGRAL - LUMÉ ESTÉTICA AVANZADA

Visión General

El proyecto es una plataforma web desarrollada en Django para la administración completa de un centro de estética. Combina un front-end público de alto nivel estético con un back-end operativo robusto, diseñado para optimizar las reservas y la comunicación automatizada.

Gestión de Clientes

Registro centralizado de pacientes y su información de contacto (WhatsApp/Email).

Control de Turnos

Agenda completa con estados dinámicos (Pendiente, Confirmada, Cancelada).

Bot Interactivo

Respuestas automáticas e integración de webhook para atención 24/7 vía WhatsApp.

Blog CMS

Publicación de artículos y noticias categorizadas para posicionamiento SEO.

Arquitectura del Sistema

Estructura Modular (Apps)

El proyecto Django está dividido en dos aplicaciones principales para separar responsabilidades:

APP1 (Módulo de Contenido / CMS)

Gestiona el contenido público. Contiene los modelos Blog (Entradas con autor, extracto, imagen destacada, control de publicación) y Category (Categorías de artículos con generación automática de URLs amigables o slugs).

APP2 (Gestión Core & Negocio)

Es el núcleo administrativo del centro. Maneja modelos de negocio como Client, Service (Servicios con duración y precio), Appointment (Citas y agenda), y toda la lógica del Bot de WhatsApp (BotResponse, BotSession y ProfileConfig).

Módulo de Gestión

Vistas y Entidades Principales

El sistema proporciona un panel de control intuitivo accesible a través de múltiples rutas operativas:

Vista / Modelo Descripción de Funcionalidad
Dashboard (/dashboard/) Vista general (dashboard_citas) que muestra métricas rápidas y el listado de las próximas reservas del día.
Clientes (/clientes/) Administración de pacientes. Guarda nombre, teléfono (formato WhatsApp), email y notas clínicas/observaciones.
Servicios (/servicios/) Catálogo de tratamientos. Incluye nombre, descripción, duración, precio, imagen y listado de beneficios.
Citas (/citas/...) Gestión de la agenda. Permite actualizar el estado de la cita (Pendiente, Confirmada, Completada, Cancelada) y exportar el listado completo.

Bot de WhatsApp

Automatización de Mensajería

El sistema cuenta con un Gateway de WhatsApp integrado mediante Webhooks (/api/whatsapp/webhook/) para automatizar la atención primaria.

Respuestas por Keyword

El modelo BotResponse permite definir palabras clave y las respuestas automáticas exactas que el bot enviará.

Máquina de Estados

BotSession rastrea el embudo del usuario (INICIO, ELIGIENDO_SERVICIO, ELIGIENDO_FECHA, ESPERANDO_PAGO).

Configuración Dinámica Institucional
A través del modelo ProfileConfig, el administrador define parámetros globales como el mensaje de bienvenida por defecto, la dirección, horarios, y las instrucciones de pago/CBU.

Módulo de Blog

Gestor de Contenidos

Herramienta diseñada para el posicionamiento SEO y la fidelización mediante artículos de estética y salud.

  • Generación Automática de Slugs Al crear un artículo (Blog) o categoría (Category), el sistema sobrescribe el método save() para autogenerar una URL amigable, asegurando unicidad incluso si los títulos se repiten.
  • Categorización (M2M) Relación de muchos a muchos (ManyToMany) con el modelo Categorías, permitiendo que un post pertenezca a varios temas a la vez.
  • Control de Publicación Diferenciación entre borradores y artículos publicados utilizando los campos booleanos published y de fecha published_at.
